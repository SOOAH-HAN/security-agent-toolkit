## 6교시 · 허용 목록 · 규칙 순서

### 문제 6-1 · 학원 방화벽은 허용 목록일까 차단 목록일까

- (가) 포트 443 · 445 · 3389 마다 「열림 · 드롭 · 거부」 판정과 근거(`curl` 문구 · Wireshark 화면)를 한 줄씩 적어 주세요.
  - 쓸 내용: 「443: 열림 — Port test successful!」처럼 포트마다 한 줄, 판정과 근거
  - 답:
443: 열림 — Port test successful!이 출력되어 연결에 성공했다.
445: 드롭 의심 — curl: (28) Connection timed out이 출력되어 5초 동안 응답이 없었다. Wireshark에서 SYN 재전송과 응답 유무를 추가로 확인해야 한다.
3389: 연결 성공 — Port test successful!이 출력되어 연결에 성공했다. Wireshark에서 SYN/ACK 응답이 왔는지 확인해 최종 판정한다.

- (나) 🔍 이 결과로 보면 학원 방화벽은 허용 목록과 차단 목록 가운데 어느 쪽에 가까운가요? 근거가 된 포트를 들어 적어 주세요.
  - 쓸 내용: ① 허용 목록 / 차단 목록 / 알 수 없음 가운데 하나 ② 근거가 된 포트와 그 결과 ③ 안내 6.1 표의 어느 줄과 맞는지
  - 답:
  답: 알 수 없음 — 443번과 3389번 포트는 `Port test successful!`이 출력되어 연결에 성공했고, 445번 포트는 `Connection timed out`과 Wireshark의 SYN 재전송이 확인되어 드롭이 의심되었다. 세 포트가 모두 열린 것도 아니고, 웹 포트만 열리고 나머지 두 포트가 모두 막힌 것도 아니므로 안내 6.1 표의 조건과 정확히 일치하지 않는다. 따라서 세 포트의 결과만으로 학원 방화벽이 허용 목록인지 차단 목록인지 확정하기 어렵다.
  현재 확인한 세 포트 중 443과 3389는 연결에 성공했고, 445는 응답이 없어 드롭이 의심된다. 따라서 세 포트의 결과만으로 학원 방화벽이 허용 목록인지 차단 목록인지 확정하기는 어렵다. 안내 6.1 표의 각 조건과 비교해 판단해야 한다.

- (다-1) 포트 세 개만 보고 내린 판단에는 어떤 한계가 있을까요? 더 확실하게 알려면 무엇을 더 해야 할까요?
  - 쓸 내용: ① 한계 한 가지 ② 더 해야 할 시험 한 가지
  - 답:
  포트 세 개만 시험했기 때문에 학원 방화벽의 전체 정책을 확실하게 알 수 없다는 한계가 있다. 더 확실하게 판단하려면 다른 포트도 추가로 시험하고, Wireshark에서 연결 요청과 응답 패킷을 확인해야 한다.

- (다-2) 6번 필터(`tcp.flags.syn == 1 && tcp.flags.ack == 0`)로 바꾸니 2번 필터 화면에서 어떤 패킷이 사라졌나요? 한 PC 가 여러 포트로 연결을 시작한 것을 찾을 때 이 필터를 쓰는 이유는 무엇일까요?
  - 쓸 내용: ① 사라진 패킷의 종류 ② 시작 SYN 만 모아 볼 때 알 수 있는 것
  - 답:
SYN 필터로 바꾸면 서버가 보내는 SYN/ACK·RST 응답 패킷과 연결 후 주고받는 데이터 패킷이 사라지고, 연결을 시작하는 SYN 패킷만 남는다. 이를 이용하면 한 PC가 짧은 시간에 여러 포트로 연결을 시도하는지 확인할 수 있어 포트 스캔이 의심되는 행동을 찾는 데 도움이 된다.
