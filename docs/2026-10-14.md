##찾아본 것

서버에서 로그를 옮기고 백업하는 방법:

서버에서는 터미널 명령어를 사용해 로그 파일을 관리한다. cp는 원본 파일을 유지하면서 복사본을 만들고, mv는 파일을 다른 위치로 옮기거나 이름을 변경한다. 로그를 백업할 때는 원본을 보존하고, 백업한 파일이 정상적으로 복사되었는지 확인해야 한다.

##오늘 새로 쓴 명령

touch: 빈 파일을 생성한다.

cp: 파일을 복사한다.

mv: 파일을 이동하거나 이름을 변경한다.

mkdir: 폴더를 생성한다.

cat: 파일 내용을 터미널에 출력한다.

rm: 파일을 삭제한다.

Tab: 파일명이나 폴더명 자동 완성에 사용한다.

찾은 옵션

폴더째 복사: cp -r

덮어쓰기 전에 묻기: cp -i

폴더째 지우기: rm -r

mv의 두 가지 쓰임

이름 바꾸기: mv b.log c.log — b.log의 이름을 c.log로 변경했다.

옮기기: mv c.log backup/ — c.log를 backup 폴더 안으로 이동했다.
