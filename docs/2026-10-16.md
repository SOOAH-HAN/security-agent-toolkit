# 2026-10-16 아침 과제 12 — Vim

## 핵심 개념
- Vim은 터미널에서 텍스트 파일을 편집하는 도구다.
- 입력 모드와 명령 모드를 구분해서 사용한다.
- 파일을 수정한 뒤에는 저장해야 변경 사항이 반영된다.

## 명령어 정리
| 명령어 | 기능 |
|---|---|
| `i` | 입력 모드로 전환 |
| `Esc` | 명령 모드로 돌아가기 |
| `:wq` | 저장하고 종료 |
| `:q!` | 저장하지 않고 종료 |
| `dd` | 현재 줄 삭제 |
| `yy` | 현재 줄 복사 |
| `p` | 붙여넣기 |
| `u` | 실행 취소 |
| `G` | 파일 마지막 줄로 이동 |
| `/WARN` | WARN 검색 |
| `:%s/WARN/ERROR/g` | 파일 전체에서 WARN을 ERROR로 변경 |

## 실습 결과
- 텍스트 파일을 만들고 로그 내용을 입력했다.
- 저장하고 종료하는 방법과 저장하지 않고 종료하는 방법을 연습했다.
- 줄 삭제, 복사, 붙여넣기, 실행 취소를 연습했다.
- WARN을 ERROR로 변경하고 저장된 결과를 확인했다.
- 잘못 입력한 줄을 삭제하고 다시 저장했다.

## 헷갈렸던 점
- `:wq`는 파일에 입력하는 일반 문장이 아니라 Vim 명령 모드에서 실행하는 명령어다.
- 파일을 저장하지 않은 상태에서는 변경 사항이 반영되지 않을 수 있다.
- Vim을 강제로 종료하면 임시 스왑 파일이 남을 수 있으므로 원본과 실행 중인 프로세스를 확인한 뒤 정리해야 한다.

## 배운 점
Vim은 입력 모드와 명령 모드를 구분하는 것이 중요하다. 실수했을 때는 파일 내용을 확인하고 필요한 부분만 수정한 뒤 저장하는 습관을 들여야겠다.
