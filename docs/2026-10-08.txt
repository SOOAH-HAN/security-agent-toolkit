## 오늘 새로 쓴 명령
`git config`, `git add`, `git commit`, `git push`

## 찾아보고 알게 된 것

### add · commit · push는
- `git add` : 올릴 파일을 선택해서 **staged 상태로 만드는 것**
- `git commit` : 선택한 변경 내용을 **내 PC의 Git에 기록으로 남기는 것**
- `git push` : commit한 내용을 **GitHub 원격 저장소로 보내는 것**

즉, **add → commit → push** 순서로 진행한다.

### untracked · tracked · staged는
- `untracked` : Git이 아직 관리하지 않는 파일
- `tracked` : Git이 관리하고 있는 파일
- `staged` : 다음 commit에 포함하도록 `git add`로 선택한 상태
