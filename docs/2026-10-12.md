##찾아보고 알게 된 것

보안 담당자가 패킷을 직접 열어 보는 이유는 네트워크 통신 내용을 확인하고 의심스러운 접속이나 이상 징후를 분석하기 위해서다.

패킷은 네트워크를 통해 데이터를 주고받을 때 전송되는 데이터 단위다.

Npcap은 Windows에서 네트워크 패킷을 캡처할 수 있도록 지원하는 도구다.

|(파이프)는 앞 명령어의 출력을 뒤 명령어의 입력으로 전달한다. 예를 들어 tasklist | grep Code는 프로세스 목록에서 Code가 포함된 줄을 찾는 데 사용한다.
