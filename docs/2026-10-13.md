##오늘 새로 쓴 명령

cat: 파일의 전체 내용을 화면에 출력한다.

grep: 파일에서 원하는 단어가 포함된 줄을 검색한다.

##찾아보고 알게 된 것

보안 담당자는 서버 로그에서 로그인 실패나 네트워크 연결 끊김 같은 기록을 확인해야 한다. 로그가 많을 때 grep을 사용하면 필요한 기록이 포함된 줄만 빠르게 찾을 수 있어 문제 상황을 확인하는 데 도움이 된다.

오늘 sample.log 파일을 직접 만들고 명령어를 실행해 보았다. grep "실패" sample.log로 로그인 실패 기록 두 줄을 찾았고, grep -n "끊김" sample.log으로 해당 기록이 4번째 줄에 있다는 것을 확인했다. grep -c "실패" sample.log의 결과는 2로, 로그인 실패가 포함된 줄이 두 개라는 것을 알게 되었다.

##막힌 것

오늘 실습에서는 명령어 실행과 결과 확인 과정에서 막힌 부분이 없었다.
