# 1과목 회고 (한수아)

## 내가 만든 것
-보안 로그와 LLM 판단 결과를 바탕으로 데이터를 정리하고, 위험도별 경보를 집계해 일일 보안 관제 보고서로 만드는 파이프라인을 학습했다.
보고서 제목과 파일명을 생성하고, 결과가 요구사항에 맞는지 assert로 검증하는 과정도 연습했다.

## 가장 어려웠던 것
-가장 어려웠던 점은 코드의 각 문법을 아는 것과 여러 문법을 연결해 문제를 해결하는 것이 달랐다는 점이다. 
에러가 발생했을 때 코드를 무작정 수정하기보다 트레이스백과 디버그 출력을 확인하고,
 원인을 찾아 한 부분씩 수정한 뒤 assert로 결과를 검증하는 방식으로 해결했다.

##8일 동안 가장 오래 막혔던 것
-배운 문법을 실제 코드에 적용하고, 여러 조건을 조합해 원하는 결과를 만드는 부분에서 어려움을 느꼈다.
특히 함수의 매개변수와 인자, 딕셔너리의 키 이름, 문자열의 대소문자와 공백, 조건문의 비교 기준을 정확하게 이해하고 연결하는 데 시간이 필요했다.
## 리뷰에서 찾은 것과 고친 것
-assert는 코드가 실행되는지만 확인하는 것이 아니라, 결과가 기대한 규칙과 일치하는지 검사한다는 점을 복습했다.
조건에 맞는 값인지, 함수가 올바른 값을 반환하는지, 결과의 줄 수가 맞는지 등을 검사하는 방법을 연습했다.
SyntaxError: 콜론이나 괄호 등 문법 오류를 수정했다.
KeyError: 딕셔너리에 실제로 존재하는 키 이름을 확인했다.
NameError: 함수에서 필요한 값을 매개변수로 전달하도록 수정했다.
논리 에러: strip()과 lower()로 문자열을 정리하고, 조건과 출력 순서를 요구사항에 맞게 수정했다.
